## Preservation And Limits

No Cube Cobra card membership, printing, or tag writes were performed. Snapshot v558,
1,004 mainboard cards, and 1,058 total slots remain the underlying data. The prior
dirty checkout and deployment repository were left intact; a Git bundle backs up
the initial website state.

Testing used browser emulation, not a physical iPhone. The private editor requires
BOONBOX and an authenticated tunnel; it is not an unauthenticated public edit page.
Printing searches require Scryfall access. A pre-existing moderate stream-json
denial-of-service advisory remains; its suggested remediation is a breaking major
upgrade, not included in this frontend release.

The public repository includes its source. Secrets, private backups, logs, publication
state, and the writable API are outside GitHub Pages. Regression tests use a frozen
copy fixture so Oscar's future text edits, including filling Blink, are not rejected
merely for changing today's wording.
