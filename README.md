# Winning in Style Cube Health

Published visual synergy and card-quality report for the public Winning in Style Cube Cobra list.

The report is generated from a dated Cube Cobra snapshot, Scryfall metadata and rules text, and historical official public 17Lands Powered Cube datasets. Research measurements are not live results for this cube.

The generator, taxonomy, regression tests and reproducible data inputs are preserved in [tooling](tooling/README.md). The [September 2026 refactor report](tooling/reports/REFACTOR_20260904.md) documents the v556 tag update and verification boundaries.
